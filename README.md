Pixlynote
​Pixlynote is a self-contained, single-file social photo and notes web application built with HTML, Tailwind-style utility CSS, and vanilla JavaScript. It runs directly in any modern browser with no build step required and persists user state locally via localStorage (with optional Firebase and Gemini API integration).
​Features
​Home Feed & Stories: Browse photo posts and interactive stories, like/save/comment/share posts, create new photo posts or Vibe Notes, and use Find Creators to Follow to open the Discover Creators modal with search and random shuffle.
​Explore: Search and browse community posts and Vibe Notes across creators.
​Profile & Multi-Account Switching:
​Switch between accounts (personal and business profiles) or create new accounts.
​Browse Posts, Notes, Replies, Saved (Photos & Notes), and Liked tabs with per-account data isolation.
​Tap Followers or Following on any profile to search, explore creator profiles, send direct messages, follow back, or remove followers.
​Interactive note cards with an outline heart by default that fills red when liked.
​Notifications & Direct Messages: Cross-account activity notifications with unread indicators and an in-app messaging modal.
​Highlights & PixAI: Story highlight creation and carousel viewer, plus optional PixAI assistant integration.
​Getting Started
​1. Download or extract index.html from index_html.zip.
​2. Open index.html directly in your browser—or host it on GitHub Pages, Netlify, Vercel, or any static web server.
​3. (Optional) Add your Google Gemini API key or Firebase config inside index.html if you want cloud sync or AI features enabled.
